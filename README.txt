AMANE STORE - STEP 2

This package contains the updated index.html with the COD checkout connected to the Supabase create-order Edge Function.

Before uploading to GitHub:
1. Open index.html.
2. Find SUPABASE_PUBLISHABLE_KEY.
3. Replace PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE with your Supabase publishable key.
4. Do NOT use a secret/service-role key.
5. Upload index.html to the root of the GitHub repository, replacing the old one.

Current limitation: online payment is intentionally disabled until Razorpay is integrated.
