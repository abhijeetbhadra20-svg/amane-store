# Amane Store — Frontend Starter

Static, GitHub Pages-ready frontend for Amane Store. No backend, database, payment gateway, or login is connected yet.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Put your own images
Place your images in `assets/` using these filenames (or change the `data-image` values in `index.html`):

- hero.jpg
- category-dresses.jpg
- category-tops.jpg
- category-bottoms.jpg
- category-coords.jpg
- category-accessories.jpg
- category-sale.jpg
- product-1.jpg through product-5.jpg

## GitHub Pages
Upload all files to a repository. In GitHub: Settings → Pages → Deploy from a branch → choose your main branch and `/ (root)`.
